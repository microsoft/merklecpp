Method

Observed, not simulated

Each scene constructs the same production-shaped fixture used by tiles_proofs: full tiles cover the compacted prefix and an in-memory tree owns the frontier. The highlighted nodes are the elements returned by the real ProofEngine.

Inclusion scenes are checked byte-for-byte against Tree::path(). The consistency scene is verified with ProofEngine::verify_consistency() before it reaches this page.
